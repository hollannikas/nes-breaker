# NES Breaker

![Build Status](https://github.com/hollannikas/nes-breaker/actions/workflows/build.yml/badge.svg)

An 8-bit NES ROM project written in 6502 assembly using the `cc65` toolchain.

## Building

Requires `cc65` installed on your system.

```bash
make clean
make
```

The resulting `game.nes` file can be played in any NES emulator.
